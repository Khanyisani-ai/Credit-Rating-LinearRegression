# Credit-Rating-LinearRegression
This is just a simple LinearRegression model:
The aim of this study is to determine which variable between age, education and income has a positive relationship with credit rating. The file being used in this analysis is the Credit.txt file which was included onto this project. 
When looking for linearity between the different variables, I discovered that there is a strong relationship between income and credit rating. The higher the income, the higher the credit rating. 
In addition, there were more females than males in this analysis and majority of the individuals within the dataset are married.
